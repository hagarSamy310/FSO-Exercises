# Full Stack Open - Exercises

This repository contains my solutions for the **Full Stack Open** course exercises offered by the University of Helsinki.

Each part of the course has its own folder, and inside them you’ll find the corresponding exercise files (Markdown, code, and diagrams).

## About the Course

[Full Stack Open](https://fullstackopen.com/en/) focuses on modern JavaScript-based web development, covering topics such as:
- React, Redux, Node.js, MongoDB, and GraphQL  
- TypeScript, testing, and CI/CD  
- Containers, React Native, and more
